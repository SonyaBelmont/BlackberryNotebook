# BlackberryNotebook 0.2 prototype

Обновлённый прототип личного офлайн-блокнота для Android.

## Что изменено в версии 0.2
- Иконка приложения заменена на черничную.
- Большая кнопка на главном экране теперь: **Новая заметка**.
- Поиск убран в отдельную кнопку-лупу.
- Добавлены сменные фоны списка заметок:
  - Чистый чёрный
  - Черничная дымка
  - Ночная черника
  - Графит и ягода
  - Кровоглотик
- Экран редактирования и текстовые поля оставлены тёмными/чёрными для удобства чтения.
- Поле **Когда нужно** теперь текстовое.
- Большая нижняя кнопка в заметке теперь: **Сохранить**.
- Статус **Сделано** перенесён в меню заметки.
- Будильник переработан: теперь есть отдельный экран с кнопками **Отключить** и **Отложить на 5 минут**.
- Автосохранение при выходе сохранено.

## Сборка APK через GitHub
В архив уже включён workflow:
`.github/workflows/android.yml`

Если вы загружаете проект в новый GitHub-репозиторий:
1. Загрузите содержимое архива целиком.
2. Убедитесь, что скрытая папка `.github` тоже загружена.
3. Откройте **Actions**.
4. Выберите workflow **Android APK**.
5. Нажмите **Run workflow**.
6. Готовый APK появится в **Artifacts**.
