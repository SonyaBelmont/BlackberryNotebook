# Блокнот — Android-прототип 0.1

Личный блокнот без аккаунтов, рекламы и интернета. Тёмная тема: графит + чернично-фиолетовый `#9275BD`.

## В версии 0.1

- Новая заметка с немедленным вводом, автоматическим сохранением при выходе
- Лента по времени создания; редактирование не меняет место заметки
- Поиск по тексту, участникам и комментарию к будильнику
- Дополнительные дата/время, участники, прикрепление изображений
- Будильник с комментарием и уведомлением Android
- «Сделано»: приглушённая заметка остаётся на своём месте
- SQLite и фотокопии в локальном хранилище приложения; интернет не нужен

## Как собрать APK в GitHub

1. Создайте пустой GitHub-репозиторий и загрузите содержимое этой папки **в корень репозитория** (включая скрытую папку `.github`).
2. Откройте **Actions → Android APK → Run workflow**. Если Actions не активированы, включите их для репозитория.
3. После успешной сборки откройте запуск, раздел **Artifacts**, скачайте `BlackberryNotebook-debug-apk` и распакуйте ZIP — внутри `app-debug.apk`.
4. Перенесите APK на Android и установите, разрешив установку из этого источника, если телефон попросит.

Android Studio: откройте эту папку как проект и выполните **Build → Build APK(s)**.

## Ограничения пробной версии

- Не проверена сборка на реальном Android-устройстве в текущей среде: нет установленного Android SDK. Сборка предусмотрена через GitHub Actions.
- Будильник реализован системным уведомлением со звуком, **не** непрерывным звонком до отключения. В Android 12+ точность зависит от разрешения точных будильников; без него используется менее точное системное планирование. В Android 13+ нужно разрешить уведомления.
- Не реализованы ручной экспорт/импорт резервной копии и отдельный экран будильников.
- Фото копируются во внутреннее хранилище приложения; при удалении приложения локальные данные могут быть потеряны. Не используйте пробник как единственное место для важных записей.
