# Черничный блокнот 0.4 — обои и удаление заметок

Обновление версии 0.3. Восемь тем оформления списка: чёрная и семь иллюстрированных. Все старые программные фоновые узоры удалены. В качестве фона «Кровоглотик» используется милый зверёк с большими ушами и крыльями летучей мыши, выбранный после уточнения образа. В редакторе фон остаётся чёрным, шрифт системный.

В меню открытой заметки (⋮) появился пункт «Удалить заметку». Перед окончательным удалением показывается подтверждение. Удаляются сама заметка, её прикреплённые фотографии и запланированный будильник. Завершённые записи по-прежнему приглушены, а не удаляются.

## Обновление без потери записей
Android applicationId не изменён: `com.example.blackberrynotebook`. База SQLite имеет ту же версию схемы. versionCode увеличен до 4. Для обновления поверх установленного APK необходима та же подпись приложения. При выпуске debug APK на другом GitHub runner подпись может отличаться: в таком случае не удаляйте старую программу, иначе локальные заметки будут потеряны. Перед обновлением сохраните важные записи отдельно.

## Как собрать
В корне проекта есть `.github/workflows/android.yml` (Java 17, Gradle 8.9, setup-android v4). Загрузите всё содержимое папки проекта в корень GitHub-репозитория и запустите **Actions → Android APK**. Итоговый APK появится в **Artifacts**.

Здесь доступны проверка исходных файлов и изображений, но Android SDK отсутствует, поэтому завершённая APK-сборка в этой среде не подтверждена. Точное время и полноэкранное отображение будильника зависят также от разрешений Android.
